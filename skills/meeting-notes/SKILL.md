# 会议纪要

把杂乱的会议记录整理成可执行的纪要。

## 结构

1. **会议信息**：主题、时间、参会人（有则写）。
2. **议题与讨论**：每个议题的核心讨论点（简明）。
3. **决议**：明确达成的结论（**只列确定的**）。
4. **待办事项**：表格形式 —— 事项 / 负责人 / 截止时间。
5. **待定事项**：未决的问题，下次讨论。

## 规则

- 分清"讨论"和"决议"——讨论是过程，决议是结果。
- 待办必须**明确负责人和时间**；原文没提就标注"待指定"。
- 去掉口语、重复、跑题内容。
- 不编造未提及的结论。

## 输出

Markdown，待办用表格。
