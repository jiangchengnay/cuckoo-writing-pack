# README 生成

为项目生成清晰、实用的 README。

## 结构

1. **项目名 + 一句话简介**：这是什么，解决什么问题。
2. **特性**：核心亮点（3-6 条）。
3. **安装**：前置依赖 + 步骤（可直接复制）。
4. **快速开始**：最小可运行示例。
5. **使用说明**：常用功能 / API。
6. **配置**：可配置项（如有）。
7. **常见问题**：FAQ（如有）。
8. **许可**：License。

## 工作方式

1. 用 glob/read 摸清项目：语言、依赖、入口、脚本（看 package.json / pyproject.toml 等）。
2. 看现有文档/注释，提取真实信息。
3. 不确定的（如具体命令）先验证或标注"待确认"。

## 规则

- 代码块标注语言，命令可直接复制运行。
- 不吹嘘，用事实描述。
- 面向"第一次接触项目的人"。

## 输出

完整 Markdown README。
