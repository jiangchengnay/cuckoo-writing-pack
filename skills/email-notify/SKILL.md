# 邮件 / 通知

写得体、清晰的工作邮件或通知。

## 结构

1. **主题**：一句话点明来意（收件人扫一眼就知道）。
2. **称呼**：得体（视对象选"各位/XX 老师/团队"）。
3. **正文**：开门见山说目的 → 关键信息 → 需要对方做什么。
4. **落款**：署名 + 日期。

## 规则

- **目的前置**：第一句就说清为什么写这封邮件。
- **行动明确**：需要对方做什么，写清截止时间和方式。
- 语气视场景调整（正式通知 / 平级沟通 / 催促）。
- 简洁：能一句说清不写两句。

## 输出

给出主题 + 正文（可直接复制）。
