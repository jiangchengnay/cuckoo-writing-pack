# 周报 / 日报 / 月报

把零散的工作内容整理成结构清晰的汇报。

## 结构

1. **本周完成**：按模块/项目分组，动词开头，说清结果。
2. **进行中**：当前进度 + 预计完成时间。
3. **下周计划**：具体、可执行。
4. **风险 / 求助**：需要协调或阻塞的事项（没有就省略）。

## 规则

- 每条用"动词 + 对象 + 结果"，如"完成登录模块开发，已联调通过"。
- 不写流水账，按**成果**聚合，不按时间罗列。
- 数据说话：有数字就带上（完成 X 个、优化 Y%、修复 Z 个 bug）。
- 用户只给了零散要点时，主动补齐逻辑顺序，但**不编造**未提及的工作。

## 输出

Markdown，标题分级。语言简洁、正式。
