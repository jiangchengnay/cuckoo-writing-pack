# 方案 / 汇报

写清"为什么做、怎么做、要什么"。

## 结构

1. **背景**：现状 + 问题（为什么要做）。
2. **目标**：期望达成的结果（可衡量）。
3. **方案**：具体怎么做（分阶段/模块）。
4. **收益**：做完有什么价值（尽量量化）。
5. **资源 / 成本**：需要什么人、时间、预算。
6. **计划**：时间表 / 里程碑。
7. **风险**：可能的阻力 + 应对。

## 规则

- **结论先行**：领导/读者最关心"要什么、值不值"，先说结论。
- 收益尽量量化（省 X 小时、提升 Y%）。
- 方案要具体可执行，不空喊口号。
- 用户信息不足时，列出假设并标注。

## 输出

Markdown，结构清晰。关键数据用列表或表格突出。
