# 中文写作包（cuckoo-writing-pack）

为 [Cuckoo Code](https://github.com/wangyongpeng90/cuckoo-code) 提供一组中文写作技能。

## 包含技能

| 技能 | 用途 |
|---|---|
| `weekly-report` | 生成周报 / 日报 / 月报 |
| `tech-doc` | 写技术文档 / 设计文档 |
| `readme-gen` | 为项目生成 README |
| `meeting-notes` | 整理会议纪要（决议 + 待办） |
| `email-notify` | 写工作邮件 / 通知 |
| `polish-text` | 文案润色与改写 |
| `proposal` | 写方案 / 汇报材料 |

## 安装

插件页搜索 `cuckoo-plugin`，或：

```bash
git clone https://github.com/jiangchengnay/cuckoo-writing-pack.git ~/.cuckoo/plugins/cuckoo-writing-pack
```
